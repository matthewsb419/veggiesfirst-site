# veggiesfirst.app

The public site for Veggies First: the landing page, the privacy page and the support page.
Served by GitHub Pages at https://veggiesfirst.app (DNS at Cloudflare).

`privacy.html` and `support.html` are copies of the ones in `veggies-review`, which the app
still links to; a change to one goes into both until the app points here.
